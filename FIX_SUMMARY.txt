================================================================================

ISSUE:
  After setting up live monitoring for a repository, new PRs would NOT get
  automatic AI review comments. Comments only appeared if manually triggered.

ROOT CAUSE:
  GitHub OAuth tokens were NOT being stored in the database when users:
  1. Added a repository for monitoring
  2. Configured monitoring settings
  
  Result: When webhooks fired, token retrieval failed → no comments posted

SOLUTION:
  Store GitHub OAuth token in database at BOTH entry points:
  1. When user adds repo (/api/monitoring/repos endpoint)
  2. When user configures settings (/api/monitoring/config endpoint)

FILES MODIFIED:
  1. backend/routers/monitoring.py
     - Line 213-214: Added token storage in add_repository()
     - Line 426-428: Added token storage in save_monitoring_config()

     - Line 325-334: Improved webhook logging
